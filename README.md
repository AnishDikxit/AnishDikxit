## 🚀 Featured Projects

<details>
<summary><b>🔮 RAG Chatbot over YouTube Transcript Corpus</b></summary>

<br>

> Production-grade Retrieval-Augmented Generation system over a multi-source YouTube corpus, serving grounded multi-turn Q&A with inline source and timestamp citations at sub-4-second p95 latency.

<div align="center">

| Metric | Details |
|:---|:---|
| **Stack** | Python, LangChain, FAISS, BM25, Anthropic Claude Haiku, Ragas, React |
| **Scale** | ~23K token corpus, 5-stage pipeline (ingest → semantic chunking → hybrid retrieval → reranking → generation) |
| **Performance** | <4s p95 latency, cold-start indexing reduced 14.1s → 8.5s, 40% redundant rebuild elimination |
| **Evaluation** | 6-config ablation on 14-question Ragas benchmark: +19.7% answer relevancy, +12.9% context recall |
| **Reliability** | Tenacity exponential-backoff retries, LLM-driven query rewriter, ~99.8% transient failure reduction |
| **Repository** | [**AnishDikxit/RAG_Chatbot**](https://github.com/AnishDikxit/RAG_Chatbot) |

</div>

Engineered a hybrid retriever fusing BM25 (w=0.3) with FAISS over all-MiniLM-L6-v2 embeddings (w=0.7), re-scored by an ms-marco-MiniLM cross-encoder. Cross-encoder reranking isolated as the dominant retrieval lever at +23.5% context precision versus no-rerank baseline. Features a React-based conversational AI interface with prompt injection guardrails and responsible AI practices.

</details>

<details>
<summary><b>📈 Async Actor-Critic for Delta-Neutral Hedging (Thesis)</b></summary>

<br>

> Reinforcement learning system applying PPO actor-critic with recurrent LSTM cores to stabilize a non-Markovian hedging control problem in quantitative finance, deployed against a C++17 microsecond-per-step simulator.

<div align="center">

| Metric | Details |
|:---|:---|
| **Stack** | PyTorch, C++17, PPO, LSTM, Pybind11, Multiprocessing |
| **Scale** | 10-worker parallelized rollout pool, 8k episode convergence, microsecond-per-step C++ matching engine |
| **Architecture** | Truncated BPTT, GAE, PPO clipping, entropy regularization, recurrent LSTM core |
| **Reward Design** | Multi-objective: entropic-risk utility, tolerance-band penalty, in_flight_exposure state feature |
| **Innovation** | Restored Markov property under 50ms execution delay via reward shaping |
| **Repository** | [**AnishDikxit/async-deep-hedging**](https://github.com/AnishDikxit/async-deep-hedging) |

</div>

Implemented a complete PPO actor-critic from scratch in PyTorch with a recurrent LSTM core, designing a multi-objective reward function that restored the Markov property under a 50ms asynchronous execution delay. Self-exciting Hawkes volatility market with a native C++ matching engine interfaced via Pybind11.

</details>
